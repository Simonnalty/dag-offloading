# 算法复杂度分析（报告第 3 章素材）

记号：V = DAG 子任务数，E = 依赖边数，P = 执行位置数（本课题 P=3，端/边/云），d̄ = 平均出/入度。

## 1. 各算法复杂度

### 算法A：随机卸载
- **时间**：O(V)。每个任务独立随机选层，无任何依赖/环境计算。
- **空间**：O(V)（决策字典）。
- 说明：作为下限参照，其意义不在复杂度而在"任何有信息量的算法都应显著优于它"。

### 算法B：贪心卸载
- **时间**：O(V·P + E)。按拓扑序遍历，每个任务对 P 个候选层各计算一次就绪时刻，就绪时刻计算需要遍历其全部前驱（合计 O(E)）。总体对稀疏 DAG（E=O(V)）为线性。
- **空间**：O(V + E)。
- 局限：每任务独立决策，不感知同层排队状态（`node_free`），也不预测对后续任务的影响。

### 算法C：HEFT
- **时间**：O(V²·P)。
  - rank_upward 优先级计算：每个任务的 rank 依赖其后继，带记忆化的递归遍历整图一次，O(V + E)；
  - 主循环：V 个任务，每个任务对 P 个候选层计算 EFT，EFT 计算需遍历前驱（单任务 O(d̄)，最坏 O(V)），故主循环最坏 O(V²·P)。
  - 经典文献（Topcuoglu et al., 2002）对插入式 HEFT 给出的即为此界；本实现无插入（append-only 队列），实际更接近 O(V·P·d̄)。
- **空间**：O(V + E)（rank 表、finish 表）。
- **实测印证**（results.csv，n=100 正常带宽）：决策耗时 4.03 ms，约为贪心（2.42 ms）的 1.7 倍、随机（0.09 ms）的 45 倍，随 V 增长的趋势符合超线性。

### 算法E：E-HEFT（自设计）
- **时间/空间**：与 HEFT 同阶，O(V²·P)。选层准则从"EFT 最小"换成"归一化时间-能耗加权和最小"，每层多算一个能耗增量项（只依赖前驱与当前层，O(d̄)），不改变阶。
- 额外 O(V) 预计算参考量纲 T_ref、E_ref。
- **实测**：5.81 ms（n=100），约为 HEFT 的 1.4 倍——常数因子来自能耗增量与归一化计算。

### 算法D：DQN
- **训练**：O(Ep · V · (B · W))。Ep 为 episode 数（5000），V 为每 episode 步数（= 子任务数），每步一次批量梯度更新（B=128 样本 × 前向+反向，W 为网络参数量 ≈ 5.6k）。实测约 3.5 分钟（CPU）。
- **推理**：每任务一次网络前向 O(W)（常数），加上环境时序推演 O(d̄)，总计 O(V·W + E) —— **理论上是所有算法中线性最快的一类**。
- **实测注记**：n=100 时 D-DQN 决策耗时 25.0 ms，反而高于 HEFT——因为每步都要走一遍 Python 环境推进 + torch 前向，常数因子大。这说明"渐进复杂度低 ≠ 小规模实例上更快"，报告可作为复杂度与实测差异的讨论点。
- **空间**：O(B·V)（经验回放缓冲）+ O(W)（网络权重，仅 ~23 KB）。

## 2. 汇总表（可直接放入报告）

| 算法 | 时间复杂度 | 空间复杂度 | 实测决策耗时(n=100) | 最优适用场景 |
|---|---|---|---|---|
| A 随机 | O(V) | O(V) | 0.09 ms | 无（下限参照） |
| B 贪心 | O(V·P + E) | O(V+E) | 2.42 ms | 快速粗估、超大图 |
| C HEFT | O(V²·P) | O(V+E) | 4.03 ms | 静态环境、以时延为唯一目标 |
| E E-HEFT | O(V²·P) | O(V+E) | 5.81 ms | 时延-能耗需权衡、α 按业务可调 |
| D DQN | 训练 O(Ep·V·B·W)，推理 O(V·W+E) | O(W)（权重） | 25.04 ms | 动态/多目标环境、可离线训练的场景 |

## 3. 复杂度之外的观察（写进报告"讨论"）

1. **HEFT/E-HEFT 的 O(V²) 在 V≤100 时不是问题**（几毫秒），但千级任务图会成为瓶颈；贪心的线性复杂度此时有吸引力。
2. **DQN 的推理复杂度优势被常数抵消**：渐进上线性，但 Python 环境 + 逐任务 torch 调用的常数大。若批量化（一次前向决策多个任务）或用 GNN 融合图结构，可显著改善。
3. **P=3 很小**是本课题能轻松穷举选层的原因；若执行位置扩展为"多个边缘节点"（P 增大），HEFT 系线性于 P，DQN 动作空间线性增大但每步仍一次前向，优势会显现。
